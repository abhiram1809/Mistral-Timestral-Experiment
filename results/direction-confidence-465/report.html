Target reached: 561 completed trades.

The target was at least 465 executions combined. This run processed 30,873 chronological signals across nine independent accounts and executed 561 trades. Skipped signals are excluded. The gates remain 55% / 60% / 70% for 1× / 2× / 3×.

First: how confidence is measured now

Confidence now estimates the probability that the model gets the next price direction right. Timestral’s median chooses long or short. Its 21 quantiles give a raw probability of price moving in that direction, using the CDF at the current close. The CDF is linearly interpolated between quantiles, with endpoint values of 1% and 99% outside their range. Profit after fees is measured separately and is not promised by a high directional confidence.

For each decision, take the preceding 300 forecast origins whose outcomes exit strictly before the current entry. Put their raw direction probabilities into ten fixed bins: 0–10%, 10–20%, and so on. Count prior correct directions W and observations N in the current raw-score bin. The smoothed estimate is (W + 1) / (N + 2), a Beta(1,1) posterior mean.

A bin needs at least 20 observations. Otherwise it uses the whole past window; if that also has fewer than 20, confidence is 50% and the trade skips. Flat realized price changes count as incorrect. Leverage does not change the price-direction event, so all levels use this same directional probability. Select the highest level meeting its own fixed gate.

This replaces the old frozen, input-range-clamped pooled sigmoid. The new counts update using completed past observations. Estimates come from that changing past window, and no future price or current test outcome enters calibration. The original one-trade run is preserved. The event definition changed from positive net profit to correct forecast direction. This is a distinct strategy, not a reproduction of the original profit-gated experiment. Each row also retains a separate estimated net-profit probability at 1×, 2× and 3×.

This is a newly specified custom estimator, not an official Mistral confidence function. A 60% estimate is an estimated direction probability, not 60% statistical certainty or a promise of profit. Its observed calibration is measured below.

Errors are measured on next-bar fractional returns, avoiding deceptively high price-level R² from persistent price levels. Positive MAE improvement means lower error than predicting the next close equals the current close; a negative value means worse. The model’s 10th–90th percentile interval should cover approximately 80% of outcomes if its marginal intervals are calibrated. Mean quantile loss averages pinball loss over the 21 forecast quantiles in return units. Lower is better; its improvement compares against putting every quantile at the current close. These metrics include skipped signals. The conditional direction-accuracy column excludes unchanged realized prices only for that diagnostic; the trading policy and its calibration still count unchanged prices as directional misses.

The cases are independent chronological backtests. Each round advances 128 candidate bars per active case. The run stops after the first complete round with at least 465 executions, so the total may exceed 465. This predetermined allocation gives every case a chance to trade; it is not a single synchronized portfolio or the first 465 trades in global calendar time.

Windows, bins, prior, minimum sample size, case order, gates and stopping rule were fixed before evaluating this run’s P&L. They were not selected by return optimization. This methodology redesign follows the already-reviewed earlier results, so it is a new retrospective sensitivity study, not a clean untouched validation set.

Model, data and assumptions

  • Actual pinned official Timestral-209M checkpoint, FP32, symmetric averaging; 250 closing prices predict the next close.
  • Yahoo’s expanded daily, hourly and minute snapshots. Old quote values were retained where changes were only tiny rounding differences. Forecast caches are reused only after the complete 250-value float32 context matches exactly.
  • Ideal current-close to next-observed-close fills, including calendar gaps. Holding durations used for cost calculations are realized historical intervals. Same-close fills omit inference and execution latency.
  • Each selected signal opens and fully closes a one-bar position. Adjacent selected signals reopen and pay another entry fee, including when the model keeps the same direction. Positions are not netted across signals.
  • Per entry and exit: Reliance 10 basis points, SPY 5, FX 2. Annual financing: 8% on actual exposure above 1×; short borrow: 3%. Entry fees reduce investable exposure. Cash interest, taxes, FX carry and intrabar margin liquidation are omitted.
  • Retrospective adjusted prices and possible model-pretraining overlap limit prospective conclusions. There are no live orders, duplicated trades, forced threshold passes or bootstrap copies.

For calibration background, see Guo et al., On Calibration of Modern Neural Networks. The particular rolling histogram and smoothing rules used here are specified in the protocol.
